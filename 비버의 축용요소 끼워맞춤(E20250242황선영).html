📜 미션 시나리오 숲속 방앗간의 동력전달장치

비버 엔지니어 바비는 숲속 방앗간에 사용할 동력전달장치를 조립하고 있습니다. 장치가 안전하게 작동하려면 베어링과 축이 알맞게 끼워져야 합니다. 새로운 베어링과 축이 지급되었지만, 어떤 끼워맞춤이 되는지는 아직 알 수 없습니다. 다행히 이전에 여러 작업자가 조립했던 과거 조립 기록이 남아 있습니다. 바비는 과거 조립 기록에서 필요한 정보를 찾아 규칙을 발견하고, 그 규칙을 이용하여 새로운 부품의 끼워맞춤을 예측하려고 합니다. 바비가 새로운 부품을 올바르게 조립할 수 있도록 과거 데이터를 분석하여 규칙을 찾고, 새로운 부품의 끼워맞춤을 판별해 보세요!

📊 1열: 가공 데이터 & 정밀 도면

KS B 표준 규격

베어링과 축 치수 데이터입니다. 우측 2열 문제 해결 시 이 데이터를 참조하세요.

실시간 공차 상태
동력전달장치 도면(①본체, ②커버, ③기어, ④축, ⑤베어링)의 결합 공차 상태입니다.
작업자 이름 베어링 치수 축 지름 범위 끼워 맞춤
💡 핵심 용어 정립 (틈새 & 죔새):
• 틈새: 조립하기 전 베어링 구멍의 크기가 축의 크기보다 커서 조립했을 때 부품 사이에 남는 여유 공간(유격)을 의미합니다.
• 죔새: 조립하기 전 축의 크기가 베어링 구멍의 크기보다 커서 조립할 때 꽉 끼이거나 억지로 눌러서 들어가는 상태를 의미합니다.

⚙️ 2열: 컴퓨팅 사고력(CT) 4단계 문제 해결

STEP 1. 문제 분해 (Decomposition)

🧩 축용 기계요소 구성 요소 분해하기

축용 기계요소 조립 문제를 판별하기 위해 핵심 독립 변수인 [베어링 치수], [축 최소 수치], [축 최대 수치]의 의미를 개별 요소로 분해해보세요.

요소 1: 베어링 치수가 의미하는 속성은?
요소 2: 축 치수에서 최소 수치가 의미하는 속성은?
요소 3: 축 치수에서 최대 수치가 의미하는 속성은?
STEP 2. 데이터 추상화 (Abstraction)

🔍 복잡한 가공 데이터에서 핵심 속성 매칭하기

불필요한 세부사항을 제외하고, 1열 데이터 표에서 **특정 작업자 1명**을 골라 [베어링 치수], [축 지름 범위], [끼워 맞춤]의 핵심 데이터만 정확히 매칭해 보세요.

STEP 3. 패턴 분석 (Pattern Analysis)

🧩 치수 대소 관계에 따른 끼워 맞춤 패턴 발견하기

추상화된 치수 대소 관계 조건에 맞춰 발생하는 끼워 맞춤 패턴(헐거운, 억지, 중간)을 올바르게 매칭해 보세요.

조건 A: 축의 최대 지름이 베어링 치수보다 작음 (항상 틈새 발생) →
조건 B: 축의 최소 지름이 베어링 치수보다 큼 (항상 죔새 발생) →
조건 C: 베어링 치수가 축의 최소~최대 범위 내에 위치 (틈새 또는 죔새) →
STEP 4. 알고리즘 적용 (Algorithm Application)

⚙️ 조건문(If-Else) 알고리즘으로 부품 끼워 맞춤 판별하기

앞서 도출한 규칙 알고리즘에 새로 지급된 부품 치수를 대소 비교하여 [발생 현상]과 [최종 끼워 맞춤] 상태를 완성하세요!

🤖 CT 자동 판별 조건문 알고리즘
IF ( 축 최대 지름 < 베어링 치수 ) THEN 현상 = "항상 틈새", 결과 = "헐거운 끼워맞춤"
ELSE IF ( 축 최소 지름 > 베어링 치수 ) THEN 현상 = "항상 죔새", 결과 = "억지 끼워맞춤"
ELSE IF ( 축 최소 ≤ 베어링 치수 ≤ 축 최대 ) THEN 현상 = "틈새 또는 죔새", 결과 = "중간 끼워맞춤"
신규 베어링 내측치수 신규 가공 축 지름 범위
Ø50.00 Ø50.01 ~ Ø50.02

💡 알고리즘 대입 힌트:
1. 신규 베어링 치수와 축 지름의 최소/최대 값을 숫자로 비교하세요.
2. 축이 베어링 치수보다 완전히 작으면 "헐거운 끼워맞춤", 축이 베어링 치수보다 완전히 크면 "억지 끼워맞춤"입니다!
